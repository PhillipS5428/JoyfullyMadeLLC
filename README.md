# Website Template

A clean, static website template optimized for Netlify hosting.

## Features
- Pure HTML/CSS/JS (no frameworks)
- Dark theme styling
- Netlify configuration ready (`netlify.toml`)
- Local development server ready (`npm start`)
- Essential pages: Home, Updates, About, Contact, Privacy, Terms
- SEO basics: Robots.txt, Sitemap.xml

## Getting Started

1. **Clone the repo** (or use as a template).
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Run local development server**:
   ```bash
   npm start
   ```
4. **Deploy to Netlify**:
   - Push to GitHub.
   - Connect your GitHub repo to Netlify.
   - The `netlify.toml` file will handle the configuration.

## Customization
- Edit `style.css` to change colors and layout.
- Edit `index.html` to update the landing page.
- Add your logic to `main.js`.
